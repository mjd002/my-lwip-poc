# GPT_PROJ

Scaffolded workspace created by the assistant. Minimal Python project with a small `src` package and a pytest test.

Target Python: 3.9.6 (detected on this machine). The project `pyproject.toml` requires Python >=3.9.6 and &lt;4.0.

Files included:

- `src/main.py` - entrypoint
- `tests/test_main.py` - simple pytest test

How to run:

1. (Optional) Create and activate a virtual environment.
2. Install dependencies: `pip install -r requirements.txt` (if any).
3. Run the app: `python -m src.main`.
4. Run tests: `pytest`
